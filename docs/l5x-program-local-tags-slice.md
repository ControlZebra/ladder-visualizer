# Program LocalTags slice (#69)

- **Capability and entry points:** `parseString` and `parseDocumentString` expose schema-declared Program `LocalTags` in a separate ordered `NormalizedProgram.localTags` collection for controller and standalone Program exports.
- **Model:** Each local retains its program owner and `Program` scope, name, type, UID fields, dimensions, radix, access, verification, description, comments, and every supported `DefaultData` representation in source order through shared tag-value types. Missing and empty collections yield `[]`; supported defaults do not make parsing partial.
- **Schema evidence:** `ProgramType/LocalTags` is optional and uses `ArrayOfAOILocalTagType`; `LocalTag` repeats zero or more times. The local tag type has optional attributes and `Comments`, `DefaultData`, and `Description`. The pinned v33, v34, and v35 XSDs use the same definitions. Earlier v17–v32 behavior is checked with focused parser inputs, without claiming XSD validation.
- **Scope:** Controller and Program tags, program locals, and AOI locals remain distinct collections. FBD operand lookup treats ordinary program tags and program locals as one program scope; same-name declarations in that scope are ambiguous. Controller scope remains outer. Scope-aware tag queries expose candidates without choosing precedence for name collisions.
- **Comparison:** `diffControllers` reports local additions, removals, defaults, and metadata changes in `ProgramDiff.localTagDiffs`, separate from ordinary `tagDiffs`. Local declarations participate in the program change and aggregate tag summary counts, including when an entire program is added or removed. Unchanged programs omit the optional collection; local declaration order alone is not a semantic edit.
- **Scalar precision:** Integer defaults outside JavaScript's safe integer range remain exact strings in `defaultValue`; safe integers and finite fractional values remain numbers. The shared conversion applies to L5K and decorated scalar defaults.
- **Unsupported policy:** Unsupported default-data encodings or nodes and unrepresentable dimensions remain in document fragments and produce precise partial diagnostics. AOI LocalTags, program parameters, and UI presentation are outside this slice.
- **Tests and gates:** Schema-valid complete `program-local-tags-v33/v34/v35.L5X` fixtures, existing normalization fixtures, and focused absent, empty, singleton, repeated, collision, FBD, and unsupported-data tests. Run focused parser tests, `npm run test:schema`, `npm run test:conformance`, `npm run typecheck`, `npm run lint`, and `npm run test:run`.
